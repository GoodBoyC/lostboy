# Lost Boy proof-of-work screenshots

Add your own PNG screenshots to this folder. Name them `01.png`, `02.png`, `03.png`, `04.png`, `05.png`, or `06.png`.

The portfolio checks these filenames and automatically displays the screenshots you add in the proof-of-work gallery. Visitors can select a screenshot to view it larger. No code edits are required to show the numbered images.

For best readability, upload the original screenshot at its original aspect ratio. Avoid sharing screenshots containing private conversations, personal information, wallet secrets, or data you do not have permission to publish.

Lost Boy's profile portrait goes in `public/images/avatar.jpg`.
