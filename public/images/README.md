# Lost Boy avatar

Add your portrait in this folder using the filename `avatar.jpg`.

Expected project path: `public/images/avatar.jpg`

The About section automatically displays that portrait in the reserved circular image area. If you use another file format or filename, update the `avatar` path in `src/data/portfolio.ts` to match it. A clear, square portrait works best.

The generated `growth-studio.jpg` is separate hero artwork and is not used as a profile portrait.
